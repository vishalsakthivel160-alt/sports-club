# Photo folders

Drop your photos into the matching folder using these names. The extension can be
.jpg, .jpeg, .png or .webp. The site finds it automatically.

| File                                   | Used for                                                   |
| -------------------------------------- | ---------------------------------------------------------- |
| gym/gym-1 ... gym-8                    | Gym hero (1), facility cards (1-7), gym gallery (1-8)      |
| turf/turf-1 ... turf-3                 | Turf page hero (1), turf gallery                           |
| cricket/cricket-1 ... cricket-3        | Home hero slide + cricket card (1), cricket section (2)    |
| football/football-1 ... football-3     | Home hero slide + football card (1), football section (2)  |
| badminton/badminton-1 ... badminton-6  | Badminton hero + home slide (1), story section (2), gallery|
| coaches/coaches-1, coaches-2           | Head Coach (1), Assistant Coach (2)                        |
| players/players-1 ... players-3        | About page story image (1), gallery                        |
| training/training-1 ... training-3     | Home "Built for Every Player" inset (1), gallery           |
| events/events-1 ... events-3           | Gallery page hero (1), gallery                             |
| facilities/facilities-1 ... facilities-3 | Home + About image (1), Contact hero (2), gallery        |
| og-cover.jpg (in this folder's parent)  | Social sharing preview (1200x630)                          |

Tips: resize to about 1600px wide and compress (TinyPNG / Squoosh) before adding.
If you have fewer photos in a category, lower its `count` in src/data/gallery.js.
Until a photo exists, a clean placeholder tile is shown.
